# Traceroute Analysis

## Objective
Understand how packets travel across networks.

## What Traceroute Shows
- Each hop (router)
- Latency at each step

## Example Output (shortened)
1 192.168.1.1
2 isp-router
3 regional-router
...
10 google.com

## Key Insight
Each hop represents a router forwarding packets using IP routing.
This demonstrates the network layer in action.
