# Socket Programming Lab

## Objective
Understand client-server communication using TCP sockets.

## How It Works
- Server listens on port 8080
- Client connects and sends a message
- Server responds

## Output Example

Server:
connected to ('127.0.0.1', 54321)
client says: hello server

Client:
server says: hello from server

## Key Insight
This demonstrates how applications implement networking using sockets.
TCP ensures reliable delivery of messages.
